# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API103 | ユーザー登録| POST | /users |×  |
# 2.リクエスト
##　ヘッダー
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |

##　ボディ
|項目|型|必須|制約|説明|
|------|------|------|------|------|
|メールアドレス|string|〇|メール形式であること|メールアドレス|
| ログインID|string|〇|8文字以上・英数字・UNIQUE|ログインID|
|パスワード|string|〇|8文字以上・英数字混在|パスワード|

# 3.レスポンス（正常系）

- ステータスコード：201
| 項目      | 型      | 必須 | 制約        | 説明      |
| ------- | ------ | -- | --------- | ------- |
| token   | string | ○  | JWT形式（想定） | 認証用トークン |
| user_id | number | ○  |           | ユーザーID  |


## 4.レスポンス(異常系)

- ステータスコード:400

- 発生条件:メールアドレスが無効
- ログインIDまたはメールが既に存在

- メッセージ:無効なメールアドレスです

## 5.アクセスするDBテーブル
- users :(INSERT: 新規ユーザーを登録)
