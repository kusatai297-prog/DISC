# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API104 | 自分の情報取得| GET | /me |〇  |
# 2.リクエスト
##　ヘッダー
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |
| Authorization | ○ | Bearer トークン |


##　ボディ
|項目|型|必須|制約|説明|
|------|------|------|------|------|
なし

# 3.レスポンス（正常系）

- ステータスコード：200

| 項目         | 型      | 必須 | 制約 | 説明        |
| ---------- | ------ | -- | -- | --------- |
| user_id    | number | ○  |    | ユーザーID    |
| login_id   | string | ○  |    | ログインID    |
| email      | string | ○  |    | メールアドレス   |
| created_at | string | ○  |    | アカウント作成日時 |


## 4.レスポンス(異常系)

- ステータスコード:401

- 発生条件:記録がない

- メッセージ:ユーザーが存在しません

- users :(SELECT:情報の取得 )
