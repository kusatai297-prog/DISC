# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
|API101|ログイン|POST|/login|×|

# 2.リクエスト
##　ヘッダー
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |

##　ボディ
|項目|型|必須|制約|説明|
|------|------|------|------|------|
|ログインID|string|〇|8文字以上の英数字|ログインID|
|パスワード|string|〇|8文字以上の英数字でアルファベットと数字を一種類ずつ含む|パスワード|

# 3.レスポンス（正常系）

- ステータスコード：200

| 項目名   | 型     | 説明               |
|----------|--------|--------------------|
| token    | string | 認証用トークン     |

## 4.レスポンス(異常系)

- ステータスコード:401

- 発生条件:ユーザIDもしくはパスワードが不一致

- メッセージ:ユーザIDもしくはパスワードが正しくありません

## 5.アクセスするDBテーブル
- users（SELECT：ユーザー認証のため参照）
- sessions（INSERT：ログイン状態を保持）
