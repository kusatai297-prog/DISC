# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API107 | DISC結果取得     | GET| /diagnoses/disc/latest |〇|        

# 2.リクエスト
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |
| Authorization | ○ | Bearer トークン |


# 3.レスポンス（正常系）

- ステータスコード：200
| 項目名    | 型      | 説明   |
| ------ | ------ | ---- |
| result | string | 診断結果 |
|diagnosis_id|int|診断ID|
|created_at|string|診断日|


## 4.レスポンス(異常系)

- ステータスコード:404

- 発生条件:DBに該当の診断結果がない
- メッセージ:診断結果がありません

## 5.アクセスするDBテーブル

- diagnoses（SELECT:診断結果の入手）
