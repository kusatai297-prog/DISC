# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API105 | 診断履歴取得| GET | /diagnoses/history |〇  |
# 2.リクエスト
##　ヘッダー
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |
| Authorization | ○ | Bearer トークン |

##　クエリパラメータ
| 項目     | 型      | 必須 | 制約    | 説明            |
| ------ | ------ | -- | ----- | ------------- |
| limit  | number | ×  | 1〜100 | 取得件数（デフォルト10） |
| offset | number | ×  | 0以上   | 取得開始位置        |


##　ボディ
|項目|型|必須|制約|説明|
|------|------|------|------|------|
なし

# 3.レスポンス（正常系）

- ステータスコード：200

| 項目名       | 型      | 説明     |
| --------- | ------ | ------ |
| total     | number | 総件数    |
| limit     | number | 取得件数   |
| offset    | number | 取得開始位置 |
| diagnoses | array  | 診断一覧   |


##　内訳
| 項目名   | 型     | 説明               |
|----------|--------|--------------------|
|診断名|string|診断名|
|日付|string|YYYY-MM-DD|
|結果|string|診断結果|

## 4.レスポンス(異常系)

- ステータスコード:404

- 発生条件:診断結果が存在しない

- メッセージ:診断結果が存在しません

## 5.アクセスするDBテーブル
- diagnoses（SELECT:診断結果取得）
