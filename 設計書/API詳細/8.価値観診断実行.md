# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API108 | 価値観診断実行   | POST | /diagnoses/value |〇 |

# 2.リクエスト
##　ヘッダー
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |
| Authorization | ○ | Bearer トークン |


## ボディ

| 項目             | 型     | 必須 | 制約                      | 説明         |
|------------------|--------|------|---------------------------|--------------|
| diagnosis_type   | string | ○    | DISC / VALUE / STRESS  | 診断の種類   |
| answers          | array  | ○    | 空不可                    | 回答一覧     |

### answers
| 項目        | 型     | 必須 | 制約 | 説明   |
|-------------|--------|------|------|--------|
| question_id | int    | ○    |      | 質問ID |
| answer      | int    | ○    | 0〜5  | 回答値 |
# 3.レスポンス（正常系）

- ステータスコード：200

| 項目名    | 型      | 説明            |
| ------ | ------ | ------------- |
| result | string | 実行結果（success） |

## 4.レスポンス(異常系)

- ステータスコード:400
- 発生条件:発生条件：answersが不正（空、範囲外、欠損など）
- メッセージ:診断を開始できない状態です

## 5.アクセスするDBテーブル
- answers(INSERT:解答データ保存)
- diagnoses(INSERT:診断結果保存)
