# 1.基本情報
|ID|API名|メソッド|パス|認証可否|
|------|------|------|------|------|
| API109 | 価値観結果取得   | GET          | /diagnoses/value         | 〇        |
# 2.リクエスト
| 項目 | 必須 | 説明 |
|------|------|------|
| Content-Type | ○ | application/json |
| Authorization | ○ | Bearer トークン |


# 3.レスポンス（正常系）

- ステータスコード：200
| 項目名    | 型      | 説明   |
| ------ | ------ | ---- |
| result | string | 診断結果 |
|diagnosis_id|int|診断ID|
|created_at|string|診断日|



## 4.レスポンス(異常系)

- ステータスコード:404

- 発生条件:すべての問題が回答されていない

- メッセージ:すべての質問に回答してください

## 5.アクセスするDBテーブル

- diagnoses（SELECT:診断結果の挿入）
