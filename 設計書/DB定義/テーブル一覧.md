#  テーブル一覧

| テーブルID | 論理名       | 物理名     | 説明 |
|------------|--------------|------------|------|
| T001       | ユーザー     | users      | システム利用者の基本情報 |
| T002       | セッション   | sessions   | ログイン状態や認証セッション管理 |
| T003       | 診断結果     | diagnoses  | ユーザーごとの診断結果データ |
|T004|回答|answers|診断の回答保存用|

# テーブル定義

##  users（ユーザー）

| 論理名     | 物理名           | 型            | NULL | 主キー | 制約     | デフォルト                      | 説明           |
| ------- | ------------- | ------------ | ---- | --- | ------ | -------------------------- | ------------ |
| ユーザーID  | id            | BIGINT       | ×    | 〇   | PK     | 自動採番                       | 一意のユーザーID    |
| ログインID  | login_id      | VARCHAR(100) | ×    |     | UNIQUE |                            | 8文字以上の英数字    |
| メールアドレス | email         | VARCHAR(255) | ×    |     | UNIQUE |                            | 連絡用メールアドレス   |
| パスワード   | password_hash | VARCHAR(255) | ×    |     |        |                            | ハッシュ化済みパスワード |
| 作成日時    | created_at    | TIMESTAMP    | ×    |     |        | CURRENT_TIMESTAMP          | 登録日時         |
| 最終更新日時  | updated_at    | TIMESTAMP    | ×    |     |        | CURRENT_TIMESTAMP（更新時自動更新） | 更新日時         |

---

##  sessions（セッション）

| 論理名       | 物理名        | 型            | NULL | 主キー | 制約           | デフォルト             | 説明       |
| --------- | ---------- | ------------ | ---- | --- | ------------ | ----------------- | -------- |
| セッションID   | id         | BIGINT       | ×    | 〇   | PK           | 自動採番              | セッション識別子 |
| ユーザーID    | user_id    | BIGINT       | ×    |     | FK(users.id) |                   | 所有ユーザー   |
| セッショントークン | token      | VARCHAR(255) | ×    |     | UNIQUE       |                   | 認証用トークン  |
| 有効期限      | expires_at | TIMESTAMP    | ×    |     |              |                   | セッション期限  |
| 作成日時      | created_at | TIMESTAMP    | ×    |     |              | CURRENT_TIMESTAMP | 作成日時     |

---

##  diagnoses（診断結果）
| 論理名    | 物理名        | 型         | NULL | 主キー | 制約                              | デフォルト             | 説明       |
| ------ | ---------- | --------- | ---- | --- | ------------------------------- | ----------------- | -------- |
| 診断ID   | id         | BIGINT    | ×    | 〇   | PK                              | 自動採番              | 診断データID  |
| ユーザーID | user_id    | BIGINT    | ×    |     | FK(users.id)                    |                   | 診断対象ユーザー |
| 診断結果   | result     | JSON      | ×    |     |                                 |                   | 診断内容     |
| スコア    | score      | INT       | ○    |     | CHECK (score BETWEEN 0 AND 100) |                   | 数値評価（任意） |
| 作成日時   | created_at | TIMESTAMP | ×    |     |                                 | CURRENT_TIMESTAMP | 診断実施日時   |
|

        BIGINT id PK
        VARCHAR name

        BIGINT user_id FK

        BIGINT user_id FK

    }

        INT question_id

        TIMESTAMP created_at
    }
